📚 Smart Study Planner

A student-friendly productivity web app built with Next.js and Tailwind CSS to organize study tasks, manage priorities, and track learning progress.

✨ Features

- 📊 Dashboard with task and study-hour statistics
- ✅ Create tasks and mark them as completed
- 📈 Visual progress tracking
- 🏷️ Task categories and priority levels
- 🔎 Search tasks and filter by status
- ⏱️ 25-minute focus timer
- 💾 Browser-based storage to preserve tasks after refreshing
- 📱 Responsive layout for different screen sizes

🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Browser Local Storage

🚀 Getting Started

Prerequisites

Install Node.js and npm.

Installation

1. Clone or download this repository.

2. Open a terminal in the project directory.

3. Install dependencies:
   
   "npm install"

4. Start the development server:
   
   "npm run dev"

5. Open http://localhost:3000 in your browser.

📂 Project Structure

- "app/page.tsx" — main dashboard and application features
- "app/globals.css" — global styling
- "app/layout.tsx" — application layout and metadata
